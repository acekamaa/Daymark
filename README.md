# Daymark Todo List

A small webpack todo app with project grouping, task filtering, completion tracking, and browser `localStorage` persistence. Deleted tasks move to the Bin with their deletion timestamp, where they can be restored or permanently removed.

## Commands

```bash
npm test      # Run model and storage tests
npm run build # Create the production bundle in dist/
npm run server # Start the development server at http://localhost:8081
```

## Structure

```text
src/
  index.js       Webpack entry point
  ui.js          DOM rendering and user interactions
  store.js       Project and Todo models plus application state
  storage.js     localStorage serialization and loading
  style.css      Responsive application styles
  template.html  HTML document template
  store.test.js  Model and persistence tests
```

`dist/` is generated by webpack and should not be edited directly.
